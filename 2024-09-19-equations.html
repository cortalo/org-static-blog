\begin{aligned} w = \lambda + \dfrac{\mu}{\alpha z + \beta} \end{aligned}

when \(z\) is moving from \(-\infty\) to \(\infty\), the \(w\) is moving around a circle, with center at ref. page 270.

\begin{aligned} \dfrac{-2\mu\alpha^* j}{|\beta + \alpha j|^2 - |\beta - \alpha j|^2} + \lambda \end{aligned}

For a straight line \(|z-a_1| = |z-a_2|\), we want to find the center of the circle \(|\frac{1}{w}-a_1|=|\frac{1}{w}-a_2|\), we use

\begin{aligned} w=u+jv, \quad a_1 = p+jq, \quad a_2 = r+js \end{aligned} \begin{aligned} \left(\dfrac{u}{u^2+v^2}-p\right)^2 + \left(\dfrac{v}{u^2+v^2}+q\right)^2=\left(\dfrac{u}{u^2+v^2}-r\right)^2+\left(\dfrac{v}{u^2+v^2}+s\right)^2 \end{aligned} \begin{aligned} -\dfrac{2up}{u^2+v^2}+p^2+\dfrac{2vq}{u^2+v^2}+q^2=-\dfrac{2ur}{u^2+v^2} + r^2 + \dfrac{2vs}{u^2+v^2}+s^2 \end{aligned} \begin{aligned} (u^2+v^2)(p^2+q^2-r^2-s^2)+2u(r-p)+2v(q-s)=0 \end{aligned} \begin{aligned} u^2 + \dfrac{2(r-p)}{p^2+q^2-r^2-s^2}u + v^2 + \dfrac{2(q-s)}{p^2+q^2-r^2-s^2}v = 0 \end{aligned}

The center of the circle locates

\begin{aligned} \dfrac{p-r}{p^2+q^2-r^2-s^2} -j \dfrac{q-s}{p^2+q^2-r^2-s^2}=\dfrac{(a_1-a_2)^*}{|a_1|^2-|a_2|^2} \end{aligned}

now for \(\frac{1}{\alpha z + \beta}\), the line \(\alpha z + \beta\) we can choose \(a_1 = j\alpha + \beta, a_2 = -j\alpha + \beta\), the center for \(\frac{1}{\alpha z + \beta}\) is

\begin{aligned} \dfrac{-2j\alpha^*}{|\beta+\alpha j|^2 - |\beta-\alpha j|^2} \end{aligned}

then the center for \(w = \lambda + \dfrac{\mu}{\alpha z + \beta}\) is

\begin{aligned} \dfrac{-2\mu\alpha^*j}{|\beta+\alpha j|^2 - |\beta-\alpha j|^2} + \lambda \end{aligned}

body effect \(g_{mb} = (n-1)g_m\), it can also be included in \(i_d = g_m(V_g - n V_s)\)

\begin{align} g_m(V_g - V_s) + g_{mb}(0-V_s) \end{align} \begin{align} g_m(V_g - V_s) + (n-1)g_m(0-V_s) \end{align} \begin{align} g_m(V_g - V_s - (n-1)V_s) \end{align} \begin{align} g_m(V_g - nV_s) \end{align}

the impedance is \(Z_{in} = -\dfrac{2}{g_m} - Z_1\). ref.

\begin{align} I_x = g_m(-V_x-I_x \cdot \dfrac{Z_1}{2}) \end{align} \begin{align} I_x (1 + \dfrac{1}{2} g_m Z_1) = - g_m V_x \end{align} \begin{align} Z_{in} = \dfrac{2V_x}{I_x} = -\dfrac{2}{g_m} - Z_1 \end{align}

if including body effect, the impedance is \(Z_{in} = -\dfrac{2}{g_m} - nZ_1\).

\begin{align} I_x = g_m(-V_x- n I_x \cdot \dfrac{Z_1}{2}) \end{align} \begin{align} Z_1 \to n Z_1 \end{align}

The circuit may oscillate with \(C_L\) if \(C_s > n C_L\). ref1. ref2. page 139 eq 6.6

\begin{align} Z_c = -\dfrac{2}{g_m} - \dfrac{n}{j\omega C_s} \end{align} \begin{align} Y &= 1/Z_c = \dfrac{1}{-\dfrac{2}{g_m} - \dfrac{n}{j\omega C_s}}\\ &= -\dfrac{g_m j \omega C_s}{n g_m + 2j\omega C_s}\\ &= -\dfrac{2g_m\omega^2 C_s^2}{n^2g_m^2 + 4\omega^2 C_s^2} - j \dfrac{ng_m^2\omega C_s}{n^2 g_m^2 + 4\omega^2 C_s^2} \end{align}

The \(Y\) may oscillate with \(C_L\) if

\begin{align} j\omega C_L - j \dfrac{ng_m^2\omega C_s}{n^2 g_m^2 + 4\omega^2 C_s^2} = 0 \end{align} \begin{align} \omega = \dfrac{ng_m}{2C_s}\sqrt{\dfrac{C_s}{nC_L}-1} \end{align}

it may happen if \(C_s > n C_L\).
